# Проект приложения для анализа банковских операций 
## Описание:
Данный проект создан для реализации приложения в котором можно анализировать банковские операции

## Установка: 
1. Клонируйте репозиторий:
git clone ///
2. Установите зависимости:
pip install -r requirements.txt
## Использование:
python src/main.py --page main --date 2025-04-15

# Пример использования:
python src/main.py --page events --date 2025-04-15 --period M

**Тесты**:

* Тест вызова скрипта для страницы main
* Тест вызова скрипта для страницы events

### Функция with_cache
Кэширует результаты функции на указанное время

**Тесты**:

* Тест кеширует результат и не вызывает исходную функцию повторно в течение времени жизни кеша
